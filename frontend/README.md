# CeremonyGuard Frontend

React + Vite + Tailwind CSS frontend for CeremonyGuard.

## Phase 1 Scope

- Vite + React project scaffold.
- Tailwind CSS configured.
- Initial placeholder dashboard showing the CeremonyGuard title and a
  "Backend connection pending" status.

The full dashboard, ceremony management UI, and audit trail visualization are
intentionally deferred to later phases.

## Running

```bash
cd frontend
npm install
npm run dev
```

The dev server runs at http://127.0.0.1:5173.

## Build

```bash
npm run build      # production build to dist/
npm run preview    # preview the production build
```
